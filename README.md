# Kantestea

A Rust-based open-source project for the TEA Protocol.

## Installation

Install via crates.io:

\`\`\`bash
cargo install kantestea
\`\`\`

## Usage

Run the CLI:

\`\`\`bash
kantestea --help
\`\`\`
